# Начало работы

В этой главе описаны наиболее распространённые задачи в виде пошаговых инструкций.

---

## Подключение инструмента

1. Подключите шнур питания к Nord Piano 6 и к сетевой розетке.
2. Подключите педаль сустейна к разъёму **SUSTAIN PEDAL** на задней панели.
3. Подключите наушники к разъёму **HEADPHONES**, или подключите кабели от **LEFT OUT** и **RIGHT OUT** к усилителю или акустической системе.
4. **Всегда включайте Nord Piano 6 первым**, до включения усилителя или активных мониторов. При выключении первым выключайте усилитель.
5. Нажмите кнопку **POWER ON/OFF** на задней панели для включения инструмента.

> **Внимание:** Использование Nord Piano 6 на высокой громкости может повредить слух. Начинайте с низкого уровня мастера и увеличивайте постепенно.

---

## Выбор программы

Программа — основная единица хранения настроек. Каждая программа хранит полный снимок всех параметров панели. На Nord Piano 6 доступно **576 ячеек программ**, организованных в **16 банков** (A–P), по **36 программ** в каждом (6 страниц по 6 программ).

**Способы выбора программы:**
- Нажмите любую из шести кнопок **PROGRAM (1–6)** под дисплеем
- Поверните ручку **PROGRAM**
- Используйте кнопки **PAGE** для перелистывания страниц
- Используйте **BANK** (Shift + PAGE) для смены банка

---

## Просмотр списком (List View)

Ручки со значком списка (прямоугольник с тремя горизонтальными линиями) поддерживают режим списка:

1. Зажмите **Shift** и поверните ручку **PROGRAM** — откроется полный список программ
2. Прокручивайте список ручкой PROGRAM
3. Мягкие кнопки **Abc** и **Cat** сортируют список по имени или категории
4. Нажмите **Shift** ещё раз для выхода

---

## Редактирование программы

Любое движение ручки или нажатие кнопки редактирует текущую программу. Дисплей показывает «**E**» рядом с номером программы. Если загрузить другую программу без сохранения — изменения потеряются.

### Выбор нового звука пианино

1. Загрузите любую программу.
2. Нажимайте кнопку категорий **PIANO SELECT** (внизу секции Piano), пока не загорится нужный тип: GRAND, UPRIGHT, ELECTRIC, CLAV, DIGITAL или MISC.
3. Поверните ручку **MODEL** для выбора конкретного звука.

---

## Отключение защиты памяти

При поставке с завода защита памяти **включена**. Перед сохранением программ её нужно отключить:

1. Зажмите **Shift** и нажмите **SYSTEM** (кнопка Program 2) — откроется меню System.
2. Первый параметр — **Memory Protect**. Если открылся другой параметр, перейдите к нему кнопками PAGE.
3. Поверните ручку **PROGRAM**, чтобы установить значение **Off**.
4. Нажмите **Shift/Exit** для выхода из меню.

---

## Сохранение программы

1. Нажмите кнопку **STORE** один раз — индикатор STORE начнёт мигать, дисплей покажет текущую ячейку.
2. Для сохранения на то же место — нажмите **STORE** ещё раз.
3. Для сохранения в другое место — поверните ручку PROGRAM или используйте кнопки PAGE/BANK для навигации, затем нажмите **STORE**.

**Для присвоения имени программе:** используйте **Shift + STORE** (функция STORE AS...). Откроется страница ввода имени. Ручка PROGRAM выбирает символы, кнопки PAGE перемещают курсор. Нажмите STORE для подтверждения.

---

## Живой режим (Live Mode)

Live-программы — шесть специальных ячеек для выступлений. Все изменения **сохраняются мгновенно автоматически**.

1. Нажмите **LIVE MODE** — индикатор Live Mode загорится.
2. Нажмите любую из кнопок **PROGRAM 1–6** для выбора одной из шести Live-ячеек.
3. Вносите любые изменения — они сохраняются немедленно.
4. Нажмите **LIVE MODE** ещё раз для выхода в обычные банки программ.

---

## Активация эффектов

1. Загрузите программу с роялем.
2. Нажмите кнопку **Reverb ON** в секции EFFECTS. Реверберация включена.
3. Поверните ручку **DRY/WET** над селектором реверберации для регулировки баланса.
4. Нажмите кнопку **DELAY ON** и попробуйте ручки **TEMPO**, **FEEDBACK**, **DRY/WET**.

---

## Наложение пианино и семпл-синтезатора

1. Включите **Piano Layer A** (нажмите кнопку Layer A в секции Piano).
2. Включите **Sample Synth Layer A** (нажмите кнопку Layer A в секции Sample Synth).
3. Ручкой **CATEGORY** выберите категорию (например, Strings Ensemble).
4. Ручкой **SAMPLE** выберите конкретный семпл.
5. Фейдерами Layer A в обеих секциях выставьте баланс громкостей.

---

## Наложение двух звуков пианино

1. Одновременно нажмите **Piano Layer A** и **Piano Layer B**. Оба слоя включены.
2. Нажмите **Piano Layer B** (его индикатор должен мигать) для фокусировки.
3. Выберите другой звук для Layer B ручками Piano Select.
4. Отрегулируйте баланс двумя фейдерами.

> Для выключения слоя — удерживайте его кнопку Layer.

---

## Раздельные эффекты для слоёв A и B

1. Нажмите **Piano Layer A** для фокусировки. В секции EFFECTS загорится индикатор **PIANO A**.
2. Включите **Reverb ON**, затем нажмите **LAYER SEND** (Shift + кнопка Reverb ON). Теперь у каждого слоя свой уровень реверберации.
3. Установите низкий уровень **DRY/WET** для Layer A.
4. Нажмите **Piano Layer B** и установите высокий уровень **DRY/WET** для Layer B.

---

## Создание сплит-режима

1. Убедитесь, что включены и слой Piano, и слой Sample Synth.
2. Нажмите **SPLIT ON/SET** в секции PROGRAM для включения сплита.
3. Удерживайте **SPLIT ON/SET** и поворачивайте ручку **PROGRAM** для выбора точки раздела (F2–C7). Светодиод над клавиатурой укажет выбранную позицию.
4. Нажмите **KB ZONE** (Shift + кнопка Piano Layer) и назначьте слой Piano на зону **LO**.
5. Нажмите **KB ZONE** (Shift + кнопка Sample Synth Layer) и назначьте слой Sample Synth на зону **UP**.

### Настройка плавного перехода (X-Fade)

После создания сплита:
1. Нажимайте **Shift + SPLIT ON/SET** (X-FADE) для выбора режима.
2. **Значение 1** — плавный переход в диапазоне ±6 полутонов.
3. **Значение 2** — плавный переход в диапазоне ±12 полутонов.
