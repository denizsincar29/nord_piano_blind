# Меню

Nord Piano 6 имеет четыре меню: **System** (Система), **Sound** (Звук), **MIDI** и **Pedal** (Педали). Все настройки меню (кроме Local Control) действуют немедленно и хранятся постоянно до следующего изменения.

**Открытие меню:** удерживайте **Shift** и нажмите соответствующую кнопку Program.

| Меню | Кнопка |
|---|---|
| System | Shift + Program 2 (SYSTEM) |
| Sound | Shift + Program 3 (SOUND) |
| MIDI | Shift + Program 4 (MIDI) |
| Pedal | Shift + Program 5 (PEDAL) |

**Навигация по меню:** кнопки **PAGE** (влево/вправо).

**Изменение значения:** ручка **PROGRAM**.

**Выход из меню:** нажмите **Shift/Exit**.

## Меню System

### 1 — Memory Protect (Защита памяти)

- **On** (по умолчанию): операции Store заблокированы
- **Off**: сохранение программ разрешено

### 2 — Global Transpose (Глобальная транспозиция)

Транспонирует весь инструмент в полутонах. Складывается с транспозицией, сохранённой в программе.

- Диапазон: **−6 до +6 полутонов**
- По умолчанию: **Off** (0)

### 3 — Fine Tune (Точная настройка)

Регулирует общую высоту тона с шагом в цент — полезно при совместной игре с инструментами, не настроенными по эталону.

- Диапазон: **±50 центов** (±пол-полутона)
- По умолчанию: **0**

### 4 — LED Intensity (Яркость светодиодов)

Устанавливает яркость всех светодиодов панели.

- Значения: **Low** (низкая), **High** (высокая, по умолчанию)

### 5 — Version and Model Info (Версия и информация о модели)

Показывает полный номер версии установленной операционной системы.

- Поверните ручку **PROGRAM** для переключения между версией ОС и аппаратными данными модели.

## Меню Sound

### 1 — Program Level (Уровень программы)

Регулирует общий уровень выходного сигнала текущей программы (масштабирует уровни всех слоёв).

- Диапазон: **±12 дБ**
- Программу необходимо **сохранить** для фиксации этой настройки.

### 2 — Output (Выход)

Режим выходного сигнала.

- **Stereo** (по умолчанию): Left Out и Right Out несут независимые левый и правый каналы
- **Mono**: оба выхода несут одинаковый моносигнал

### 3 — Piano Pedal Noise Level (Уровень шума педали)

Устанавливает громкость эффекта педального шума для пианино, поддерживающих эту функцию.

- Требуется подключённый Nord Triple Pedal или Nord Single Pedal 2.
- Диапазон: **±6 дБ** (по умолчанию: 0 дБ)

## Меню MIDI

### 1 — Local Control (Локальное управление)

- **On** (по умолчанию): клавиатура и панель управляют внутренними звуками
- **Off**: только передача MIDI; внутренние звуки отключены

> Всегда сбрасывается в **On** при включении инструмента.

### 2 — MIDI Channel (MIDI-канал)

Глобальный канал для передачи и приёма MIDI.

- Диапазон: **1–16** или **Off**
- По умолчанию: **1**

### 3 — MIDI Control / Program / Device Change

Три отдельных подпараметра:

**Control Change Mode** — передача/приём CC и NRPN:
- Значения: Off, Send, Receive, **Send & Receive** (по умолчанию)

**Program Change Mode** — передача/приём сообщений Program Change:
- Значения: Off, Send, Receive, **Send & Receive** (по умолчанию)

**Device Change Mode** — передача/приём от физических контроллеров (педалей):
- Значения: Off, Send, Receive, **Send & Receive** (по умолчанию)

### 4 — Transpose MIDI At (Применение транспозиции к MIDI)

Определяет, к чему применяются значения транспозиции.

- **In** (по умолчанию): транспозиция применяется к **входящему** MIDI; исходящие ноты не транспонируются
- **Out**: транспозиция применяется к **исходящему** MIDI

### 5 — MIDI Out Velocity Curve (Кривая скорости нажатия)

Управляет тем, насколько нужно нажимать клавиши для достижения высоких значений velocity в исходящем MIDI.

- **Heavy** (по умолчанию): соответствует динамическому диапазону звукового движка
- **Medium**: требует меньше усилий
- **Light**: максимальная velocity достигается минимальным усилием

## Меню Pedal (Педали)

### 1 — Control Pedal (Педаль управления)

**Type (Тип):** выберите модель экспресс-педали, подключённой к разъёму **VOL/CTRL PEDAL**.

> При нажатии педали в этом меню на дисплее отображается процент, показывающий диапазон сигнала педали.

Поддерживаемые модели: Roland EV-7 (по умолчанию), Yamaha FC-7, Korg, Fatar/Studiologic, Nord SP-2.

**Gain (Усиление):** добавляет усиление к сигналу педали, если педаль не достигает полного диапазона. Диапазон: 1–10.

### 2 — Sustain Pedal Type (Тип педали сустейна)

Выбор типа педали, подключённой к разъёму **SUSTAIN PEDAL**, и её полярности.

Значения: Nord SP-1 (по умолчанию), Nord SP-2, Nord TP-1, Normally Open, Normally Closed.

### 3 — Triple Pedal Function (Функция тройной педали)

При подключённой тройной педали **левая** и **средняя** педали можно переназначить. Правая педаль всегда выполняет функцию сустейна.

**Левая педаль:** Una Corda (по умолчанию), Synth Vibrato, Program Up, Program Down.

**Средняя педаль:** Sostenuto (по умолчанию), Synth Vibrato, Program Up, Program Down.

### 4 — Foot Switch (Ножной переключатель)

Настройка разъёма **FOOT SWITCH** для моментальной педали с одной или двумя кнопками.

> Nord SP-2 и другие непрерывные экспресс-педали **не совместимы** с разъёмом Foot Switch.

**Type (Тип):** Single Open, Single Closed, Dual Open, Dual Closed.

**SW A:** функция одиночной кнопки или первой кнопки двойной педали. Значения: Synth Vibrato, Program Up, Program Down.

**SW B:** функция второй кнопки двойной педали. Значения: Synth Vibrato, Program Up, Program Down.
