# Описание Nord Piano 6 для незрячих

Добро пожаловать в руководство по Nord Piano 6 для незрячих пользователей!

## О данном руководстве

Это подробное описание управляющих элементов и функций синтезатора Nord Piano 6, специально подготовленное для незрячих пользователей. Руководство содержит детальное описание всех кнопок, регуляторов, индикаторов и функций инструмента.

## Содержание руководства

### Часть 1: Органы управления

1. [Виды управляющих элементов](01-control-types.md) — типы кнопок, регуляторов и индикаторов
2. [Секция PIANO](02-piano-section.md) — мастер-регуляторы, фейдеры слоёв, кнопки Layer, KB Zone, Octave Shift
3. [Правая половина секции PIANO](03-piano-right.md) — Dynamic Compression, Unison, KB Touch, Timbre, выбор модели
4. [Секция SAMPLE SYNTH](04-sample-synth.md) — слои, огибающая, голосовые режимы, вибрато, выбор сэмпла
5. [Секция PROGRAM](05-program-section.md) — дисплей, транспонирование, сплит, сохранение, навигация, Live Mode, меню
6. [Секция EFFECTS](06-effects-section.md) — FX Focus, Mod1, Mod2, эквалайзер, дилэй, усилитель, компрессор, реверберация
7. [Индикаторы и разъёмы](07-indicators-connectors.md) — светодиоды над клавиатурой, разъёмы задней панели

### Часть 2: Начало работы

8. [Начало работы](08-getting-started.md) — пошаговые задачи: подключение, выбор программ, редактирование, сохранение, Live Mode, наложение слоёв, сплит, эффекты

### Часть 3: Справочник

9. [MIDI](09-midi.md) — MIDI-канал, запись в DAW, Local Control, Program Change, Panic
10. [Меню](10-menus.md) — все четыре меню: System, Sound, MIDI, Pedal — каждый параметр описан
11. [Подключения](11-connections.md) — все разъёмы задней панели с типами, назначением и сводной таблицей
12. [Список MIDI-контроллеров](12-midi-controller-list.md) — полная таблица CC и NRPN

## Как пользоваться руководством

Используйте навигацию слева или ссылки выше для перехода между разделами. Каждый раздел содержит подробное описание соответствующей части инструмента с указанием расположения элементов управления.

## Источник

Данное руководство основано на оригинальной документации Nord Piano 6 (OS v1.1x, Edition C) и расширено для максимального удобства незрячих пользователей.

Текст данной документации был подготовлен волонтёром сайта [опиши-мне.рф](https://опиши-мне.рф/). Без их помощи создание этого руководства было бы невозможно.
