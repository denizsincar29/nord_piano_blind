# Секция PROGRAM

## Обзор секции

**Расположение:** Приблизительно посередине всей передней панели

**Центральный элемент:** Прямоугольный OLED-дисплей

**Назначение секции:**

Содержит настройки для:
- Секции PIANO
- Секции Sample Synth
- Эффектов
- Конфигураций разделения или транспонирования

**Функции:**
- Навигация по программам и их сохранение
- Доступ к функциям исполнения и меню настроек
- Отображение названий выбранных звуков
- Меню системных настроек, звука, педалей и MIDI
- Режим Organize для перестановки программ

## Левый верхний угол - KB SPLIT

**Расположение:** Слева сверху от экрана

### Элементы

- Подпись **KB SPLIT** на сером фоне
- Круглый индикатор **зелёного свечения**
- Подпись **ON/SET** с белой стрелкой вниз
- Чёрная кнопка

### X-FADE

**Под кнопкой:**
- Подпись **X-FADE**
- Два круглых индикатора: **1** и **2**

### Функция KB SPLIT

Клавиатура Nord Piano 6 может быть разделена на две зоны.

**Активация:**
- Нажмите **ON/SET** для активации разделения
- Удерживайте для открытия страницы разделения на дисплее

**Позиции разделения:** F2-C7 (10 положений)

**Индикация:** Светодиоды над клавиатурой указывают активную позицию.

### Функция X-FADE (Перекрестное затухание)

**Активация:** Shift + Split On/Set

**Параметры:**

- **Выкл.** - нет перекрестного затухания
- **Значение 1** - диапазон ±6 полутонов
- **Значение 2** - диапазон ±12 полутонов

## Индикатор MIDI

**Расположение:** Под KB SPLIT

Круглый индикатор **MIDI** мигает при поступлении входящих MIDI-сообщений:
- На порт MIDI In
- По USB-соединению

## Программные кнопки (1-6)

**Расположение:** Внизу почти во всю ширину секции

**Элементы:**
- Белая вертикальная широкая полоса
- Круглые индикаторы с подписями: **1, 2, 3, 4, 5, 6**
- Под каждым - чёрная кнопка

**Подписи под кнопками:**
1. **PROG INIT**
2. **SYSTEM**
3. **SOUND**
4. **MIDI**
5. **PEDAL**
6. **ORGANIZE**

**Функции:**

- **Основная:** Мгновенный доступ к ряду из шести программ в текущем банке
- **Дополнительная:** Программные кнопки при работе с меню (кнопки 2-5)

### Дополнительные функции (Shift + кнопка)

- **PROG INIT** (Shift + 1) - инициализация программы на одном слое фортепиано
- **SYSTEM** (Shift + 2) - меню системных настроек
- **SOUND** (Shift + 3) - меню настроек звука
- **MIDI** (Shift + 4) - меню MIDI настроек
- **PEDAL** (Shift + 5) - меню настроек педалей
- **ORGANIZE** (Shift + 6) - режим перемещения/замены программ в банках

## LIVE MODE и NUM PAD

**Расположение:** Слева приблизительно над кнопкой 1

**Элементы:**
- Круглый индикатор **LIVE MODE**
- Чёрная кнопка
- Круглый индикатор **NUM PAD** под кнопкой

### LIVE MODE

**Функция:**

Nord Piano 6 имеет шесть удобных концертных программ.

**Использование:**
- Нажмите **LIVE MODE**
- Затем любую из кнопок 1-6

**Особенность:** Изменения сохраняются автоматически (без необходимости ручного сохранения).

### NUM PAD

**Функция:**

Режим цифровой клавиатуры.

**Активация:** Shift + Live Mode

**Режимы навигации:**
- Постраничная навигация (по умолчанию)
- Цифровая клавиатура

## Над экраном - TRANSPOSE

**Элементы:**
- Подпись **TRANSPOSE** на белом фоне
- Круглый индикатор **зелёного свечения**
- Подпись **ON/SET** со стрелкой вниз
- Чёрная кнопка

**Функция:**

Транспонирование Nord Piano 6 с шагом **±6 полутонов** в зависимости от программы.

**Использование:**
- Нажмите и удерживайте **ON/SET** для выбора значения
- Нажатие **ON/SET** включает/выключает функцию

## Справа от TRANSPOSE

### PROG VIEW / PANIC

**Элементы:**
- Чёрная кнопка
- Надпись **PROG VIEW** сверху
- Надпись **PANIC** снизу

**PROG VIEW:**

Переключение между двумя режимами просмотра дисплея:

1. **Режим по умолчанию:**
   - Название и номер программы
   - Нижняя половина экрана: подсказки о параметрах

2. **Второй режим:**
   - Название и номер программы (мелким шрифтом)
   - Нижняя половина: текущий выбор для каждого активного слоя

**PANIC:**

**Активация:** Shift + Prog View

**Назначение:**
- При зависании нот в режиме MIDI
- Для отключения всего звучания

### STORE / STORE AS...

**Элементы:**
- Красная кнопка **STORE**
- Круглый индикатор
- Надпись «**STORE AS...**» под кнопкой

**STORE:**
- Сохранение отредактированной программы
- Существующие данные в ячейке перезаписываются

**STORE AS...** (Shift + Store):
- Сохранение программы с присвоением названия

## Справа от экрана - Регулятор PROGRAM

**Элементы:**
- Круглый регулятор чёрного цвета
- Значок прямоугольника с тремя линиями
- Слово **PROGRAM**

**Функции:**
- Выбор программ
- Установка значений параметров
- Ввод символов в названия программ

**LIST** (Shift + регулятор):
- Отображение всех программ в виде списка

**Режимы сортировки LIST:**
- **Abc** - в алфавитном порядке
- **Cat** - по выбранной категории

## PAGE/CAT и BANK

**Расположение:** Под регулятором PROGRAM

**Элементы:**
- Название **PAGE/CAT** со стрелками влево и вправо
- Две чёрные кнопки (рядом друг с другом)
- Подпись **BANK** со стрелками (по середине под кнопками)

**PAGE/CAT:**
- Навигация по страницам программ
- Каждая страница - группа из **6 программ**

**BANK** (Shift + Page):
- **36 разделов** с программами
- Разделены на **6 программных страниц**

**В режиме LIST:**
- Переключение между страницами
- Буквенно-цифровыми символами
- Категориями

## Правый нижний угол - SHIFT/EXIT

**Расположение:** На белом фоне

**Элементы:**
- Серая кнопка
- Надпись **SHIFT** сверху
- Надпись **EXIT** снизу

**Функции:**

**SHIFT:**
- Доступ к дополнительным функциям (нажать и удерживать)
- Дополнительные функции указаны под элементами управления

**EXIT:**
- Выход из меню
- Отмена текущей операции сохранения
