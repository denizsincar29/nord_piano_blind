# Nord Sound Manager

Nord Sound Manager — бесплатное приложение для управления библиотекой звуков Nord Piano 6 с компьютера. Скачайте его на **nordkeyboards.com**.

---

## Что делает Nord Sound Manager

- Загружает новые звуки пианино и сэмплы на инструмент
- Удаляет звуки, освобождая память
- Переименовывает программы
- Организует программы по банкам
- Создаёт резервные копии всех программ и звуков
- Устанавливает обновления операционной системы

---

## Подключение

1. Подключите Nord Piano 6 к компьютеру кабелем **USB Type B** (такой же, как у принтеров).
2. Запустите Nord Sound Manager. Инструмент определяется автоматически.
3. На Mac и Windows дополнительные драйверы не требуются.

---

## Окно программы

Окно разделено на две панели:

**Левая — инструмент:** показывает содержимое памяти Nord Piano 6, разделённое по разделам (Piano, Samples, Programs).

**Правая — архив:** показывает содержимое выбранной папки на компьютере.

Для передачи звука: перетащите файл из архива на инструмент. Для удаления: выберите звук в левой панели и нажмите Delete.

---

## Загрузка новых звуков

1. Скачайте файл `.npno` (пианино) или `.nsmp` (сэмпл) с nordkeyboards.com.
2. Откройте Nord Sound Manager.
3. Перетащите скачанный файл в соответствующий раздел инструмента.
4. После передачи новый звук сразу доступен на инструменте.

---

## Обновление операционной системы

1. Скачайте файл обновления ОС с nordkeyboards.com.
2. Откройте Nord Sound Manager.
3. Нажмите **Update OS** и выберите скачанный файл.
4. Не отключайте USB и не выключайте питание во время обновления.

---

## Форматы файлов

| Расширение | Содержимое |
|---|---|
| `.npno` | Звук пианино (Nord Piano Library) |
| `.nsmp` | Сэмпл-инструмент (Nord Sample Library) |
| `.nprg` | Одна программа |
| `.nbank` | Банк программ (36 программ) |
| `.nbundle` | Полный бэкап (все программы и звуки) |
