# Секция PIANO

Описание слева направо.
Слева наверху круглый регулятор MASTER LEVEL. Это главный регулятор уровня для настройки общей громкости. В крайнем левом положении – минимум, при вращении вправо – увеличение.
Под ним прямоугольная серая кнопка VIBRATO. Под кнопкой круглый индикатор, справа от него подпись: ENABLE. Это кнопка вибрато, с помощью которой можно вручную управлять сэмплами синтезаторного вибрато. Она может использоваться для применения вибрато в режиме реального времени на базе настроек частоты и количества, сделанных в разделе Sample Synth. Параметр ENABLE (Shift+Vibrato) можно использовать для включения или выключения этой функции для каждого слоя, что позволяет применять вибрато с помощью кнопки к одному слою, но не к другому, например, при раздельной настройке.
Секция PIANO.
Правее следующая секция с кнопками и регуляторами, её название PIANO.
Она включает в себя широкий спектр звуков для фортепиано и клавишных из постоянно растущей библиотеки Nord Piano, а новые звуки регулярно становятся доступны бесплатно на сайте nordkeyboards.com.
Секция выделена только визуально: светло-серый фон заголовка, такого же цвета рамка и тёмно-серый фон внутри рамки.
Левая половина секции PIANO.
Слева наверху этой секции два вертикальных регулятора-движка для двух уровней. Это фейдеры слоев A и B, которые состоят из физического ползунка и светодиодного графика, который обеспечивает визуальную индикацию текущего выходного уровня громкости слоя.
Они регулируются с помощью серых ручек, по форме близких к кубикам, слегка сужающимся к верху. Справа от обоих регуляторов вертикальные шкалы индикаторов. В каждой шкале 12 прямоугольных секций, уровень отображается заполнением этих шкал зелёной подсветкой.
Под каждым движком серая кнопка: под левым – для уровня A (LAYER A), под правым – для уровня B (LAYER B). Над кнопкой подпись ON/OFF со стрелкой вниз, ниже индикатор: маленькая круглая лампочка оранжевого свечения с подписью справа LAYER A (у второй кнопки: LAYER B).
Есть два слоя Piano: A и B. Включение второго слоя осуществляется одновременным нажатием обеих кнопок слоя. Для выключения слоя необходимо удерживать его кнопку нажатой в течение короткого промежутка времени. Чтобы переключиться с одного слоя на другой, нажмите кнопку неактивного слоя. Если оба слоя активны, выделенный слой отображается мигающим индикатором.
Нажатие кнопки слоя также позволяет сфокусировать эффекты этого слоя для редактирования, о чем свидетельствует индикатор FX FOCUS в разделе EFFECTS (он будет описан ниже), а также красным будет светиться индикатор самого слоя.
Под каждой из кнопок ещё два маленьких круглых индикатора KB ZONE зелёного свечения: LO и UP. Нажмите на кнопку KB ZONE (Shift + LAYER A или B), чтобы назначить слой в фокусе для любой из активных зон клавиатуры. Зеленые светодиоды указывают, назначен ли слой для LO (нижняя), UP (верхняя) или для обеих зон клавиатуры.
Ниже заголовок OCTAVE SHIFT со стрелкой влево и стрелкой вправо с двух сторон от названия.
Ниже две чёрные кнопки. Используйте их, чтобы переместить выбранный фортепианный слой вверх или вниз на октавы (+/- 12 полутонов). Если он назначен для всей клавиатуры, его можно переместить на одну октаву вверх или вниз. При назначении для меньшей зоны доступные значения транспонирования будут отличаться, но всегда обеспечат доступ ко всему диапазону звучания пианино. Под левой кнопкой подпись SUST PED, слева от подписи круглый индикатор красного свечения. Это настройка сустейна (Shift + левая кнопка OCTAVE SHIFT), она активирует любую подключенную педаль сустейна для выбранного слоя фортепиано. Правая кнопка подписана снизу VOL PED, слева от подписи круглый индикатор красного свечения. Это регулировка громкости (Shift + правая кнопка OCTAVE SHIFT), она активирует подключенную педаль управления/регулировки громкости для выбранного слоя Piano. Светодиодный фейдер по-прежнему можно использовать для установки максимального уровня громкости выбранного слоя.
