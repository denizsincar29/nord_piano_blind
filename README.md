# Описание Nord Piano 6 для незрячих

Подробное описание управляющих элементов и функций синтезатора Nord Piano 6, специально подготовленное для незрячих пользователей.

## 📚 О проекте

Это руководство содержит детальное описание всех кнопок, регуляторов, индикаторов и функций инструмента Nord Piano 6, организованное в виде удобной для навигации HTML-документации.

## 🌐 Просмотр документации

Документация создана с использованием [mdBook](https://rust-lang.github.io/mdBook/) и доступна в виде красивого HTML-сайта.

### Локальный просмотр

Для просмотра документации локально:

```bash
cd book
mdbook serve --open
```

Документация откроется в браузере по адресу `http://localhost:3000`.

Альтернативно, вы можете просто открыть файл `book/book/index.html` в браузере.

## 📖 Содержание руководства

1. **Виды управляющих элементов** - описание типов кнопок, регуляторов и индикаторов
2. **Секция PIANO** - левая половина секции с фейдерами и основными настройками
3. **Правая половина секции PIANO** - настройки динамики, тембра и выбор модели
4. **Секция SAMPLE SYNTH** - работа с библиотекой сэмплов и синтезатором
5. **Секция PROGRAM** - управление программами, транспонирование и настройки
6. **Секция EFFECTS** - все эффекты и их параметры
7. **Индикаторы и разъёмы** - дополнительные индикаторы и описание задней панели

## 🔧 Сборка документации

Если вы хотите пересобрать документацию:

1. Установите mdBook:
   ```bash
   cargo install mdbook
   ```

2. Соберите книгу:
   ```bash
   cd book
   mdbook build
   ```

3. Или запустите локальный сервер с автообновлением:
   ```bash
   cd book
   mdbook serve
   ```
