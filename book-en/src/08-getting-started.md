# Getting Started

This chapter walks through the most common tasks step by step. Use it as a hands-on guide the first time you explore the instrument.

---

## Hooking It Up

1. Connect the power cord to the Nord Piano 6 and to a mains power supply.
2. Connect your sustain pedal to the **SUSTAIN PEDAL** jack on the rear panel.
3. Connect headphones to the **HEADPHONES** jack, or connect cables from **LEFT OUT** and **RIGHT OUT** to an amplifier or speaker system.
4. **Always turn on the Nord Piano 6 first**, before turning on the amplifier or active speakers. When shutting down, turn off the amplifier first.
5. Press the **POWER ON/OFF** button on the rear panel to turn on the instrument.

> **Warning:** Using the Nord Piano 6 at high volumes can damage your hearing. Start at a low master level and increase gradually.

For full details on all connections, see the [Connections](11-connections.md) chapter.

## Selecting a Program

Programs are the main building blocks of the Nord Piano 6. Each program stores a complete snapshot of all panel settings — piano sound, sample synth sound, effects, split, transpose, and more. There are **576 program locations** organized into **16 banks** (A–P), each bank containing **36 programs** across **6 pages** of 6.

**To select a program:**
- Press any of the six **PROGRAM buttons** (1–6) below the display to jump to that program on the current page
- Turn the **PROGRAM dial** to scroll through programs
- Use the **PAGE** buttons to move between pages within a bank
- Use **BANK** (Shift + PAGE) to switch banks

The display always shows the current program name and number (e.g., **A:23 Pearl Drops**).

---

## List View

Dials with a list icon (a rectangle with three horizontal lines) next to their label support List View:

1. Press **Shift** and turn the **PROGRAM** dial to open the full program list
2. Scroll to any program with the PROGRAM dial — all 16 banks are accessible
3. Use soft buttons **Abc** or **Cat** to sort alphabetically or by category
4. Press **Shift** again to exit List View

The same List View is available for the **Model** dial in the Piano section and the **Category / Sample** dials in the Sample Synth section.

## Editing a Program

Any time you turn a knob or press a button, you are editing the current program. The display shows an "**E**" next to the program number to indicate unsaved edits. If you load another program without saving, your edits are lost.

### Select a New Piano Sound

1. Load any program as a starting point.
2. Press the **PIANO SELECT** category button (bottom of the Piano section) until the desired type lights up: GRAND, UPRIGHT, ELECTRIC, CLAV, DIGITAL, or MISC.
3. Turn the **MODEL** dial to scroll through available sounds in that category.

---

## Turn Off Memory Protection

When shipped from the factory, Memory Protect is **On** to prevent accidental overwriting of programs. Before you can save programs, you need to turn it off:

1. Hold **Shift** and press **SYSTEM** (Program button 2) to open the System Menu.
2. The first setting is **Memory Protect**. If a different setting is shown, use PAGE buttons to navigate to it.
3. Turn the **PROGRAM** dial to change the value to **Off**.
4. Press **Shift/Exit** to close the menu.

This setting stays Off until you change it back.

---

## Storing a Program

1. Press **STORE** once — the STORE LED flashes and the display shows the current storage location.
2. To save to the same slot, press **STORE** again.
3. To save to a different slot, turn the **PROGRAM** dial or use PAGE/BANK buttons to navigate, then press **STORE** to confirm.

**To name a program:** use **Shift + STORE** (STORE AS...) instead. A character entry page opens. Use the PROGRAM dial to select characters and the PAGE buttons to move the cursor. Press STORE to confirm.

---

## Live Mode

Live programs are six special memory slots designed for performance. Every change you make is **automatically saved instantly** — no manual Store needed.

1. Press **LIVE MODE**. The Live Mode indicator lights up.
2. Press any of the **PROGRAM buttons 1–6** to select one of the six live program slots.
3. Make any edits. They are saved immediately.
4. Switch to another live slot and return — your edits are still there.
5. Press **LIVE MODE** again to exit Live Mode and return to the regular program banks.

> If you want to permanently store a live program into a regular program bank, use the STORE function while in Live Mode.

## Activating Effects

1. Load any Grand Piano program.
2. Press the **Reverb ON** button in the EFFECTS section (bottom right). The Reverb is now active.
3. Turn the **DRY/WET** knob above the reverb selector to adjust the balance between dry and wet signal.
4. Press the **DELAY ON** button. Try the **TEMPO**, **FEEDBACK**, and **DRY/WET** controls to shape the delay character.

---

## Layering Piano with Sample Synth

1. Turn on **Piano Layer A** (press Layer A button in the Piano section).
2. Turn on **Sample Synth Layer A** (press Layer A button in the Sample Synth section).
3. Use the **CATEGORY** dial in the Sample Synth section to choose a category (e.g., Strings Ensemble).
4. Use the **SAMPLE** dial to pick a specific sample.
5. Use the respective **Layer A faders** in both sections to balance the volumes.

---

## Layering Two Piano Sounds

1. Press **Piano Layer A** and **Piano Layer B** simultaneously. Both layers are now on.
2. Press **Piano Layer B** button (if not already focused — its LED should blink).
3. Use the Piano Select controls to choose a different sound for Layer B (e.g., if Layer A has a Grand, choose an Electric Piano for Layer B).
4. Use the two faders to balance the two piano sounds.

> To turn a layer off, hold down its layer button for a moment.

---

## Setting Separate Effects for Layer A and B

1. Press **Piano Layer A** to focus it. The **PIANO A** LED in the FX FOCUS block of the EFFECTS section lights up.
2. Press **Reverb ON** and then press **LAYER SEND** (Shift + Reverb ON button). This enables independent reverb levels per layer.
3. Set a low **DRY/WET** level for Layer A.
4. Press **Piano Layer B** to focus it. Set a high **DRY/WET** level for Layer B.

Layer A is now dry; Layer B has a lot of reverb.

---

## Creating a Split

1. Make sure both a Piano layer and a Sample Synth layer are active.
2. Press **SPLIT ON/SET** in the PROGRAM section to turn the split on.
3. Hold down **SPLIT ON/SET** and turn the **PROGRAM** dial to choose the split point (F2–C7). A LED above the keyboard indicates the split position.
4. Press **KB ZONE** (Shift + Piano Layer button) and assign the Piano layer to the **LO** zone.
5. Press **KB ZONE** (Shift + Sample Synth Layer button) and assign the Sample Synth layer to the **UP** zone.
6. The Piano now plays to the left of the split point; the Sample Synth plays to the right.

### Setting Up a Split Cross-Fade (X-Fade)

After creating the split:
1. Press **Shift + SPLIT ON/SET** (X-FADE) to cycle through crossfade settings.
2. **Value 1** — sounds blend over a ±6 semitone range at the split point.
3. **Value 2** — sounds blend over a ±12 semitone range.

This creates a smooth, gradual transition between the two sounds instead of a hard cutoff.

Use the **OCTAVE SHIFT** buttons in the Piano and Sample Synth sections to adjust the pitch range of each layer within its zone.
