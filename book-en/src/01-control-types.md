# Types of Control Elements

Description of indicators, buttons, and other controls on the front panel. The panel itself is red, with the large model name NORD PIANO 6 and the inscription VIRTUAL ACTION TECHNOLOGY 88 placed at the bottom right above the keyboard. An identical instrument with a reduced keyboard is completely identical in terms of the set and arrangement of keys. The only difference is the size and full name: VIRTUAL ACTION TECHNOLOGY 76.

## Types of Control Elements

**FADERS** consist of a physical slider and an LED indicator.

**VOLUME REGULATORS** - knobs without fixed start and stop positions, which are used to navigate parameters and settings. For most settings, the regulators correspond to the saved values when the program loads. When the knob is turned, the value of the corresponding parameter is tied to the new knob position. To track the current value of any knob parameter, press and hold the SHIFT button while turning that knob.

**Selection buttons** are used to select one setting from a group of available options. They are equipped with a set of round or triangular LED indicators indicating the current setting. Press the button several times to switch between possible settings.

**On/off buttons** are used to activate a function or group of such functions, such as effects, and an LED next to them should light up, indicating the on/off state.

**Buttons with hold function**. Some buttons can be held down to access a function or perform additional settings, as indicated by text accompanied by a down arrow.

**SHIFT button**. Many controls on the Nord Piano 6 panel have additional functions that are indicated directly below them. To access these additional functions, press and hold the SHIFT key during control. The Shift button is also used to exit menus or cancel the current save operation.

**Note:** All buttons have a rectangular shape with a protruding part in the form of an elongated oval. Only colors and orientation differ: horizontal or vertical.

**Note 2:** All indicators are LED, they look like small round bulbs or glowing triangles. The description will specify the glow color only in cases where it is confirmed by examples of illumination in the instrument images.

**Note 3:** The inscription under the button indicates an additional function of this button, which is activated by pressing the combination of the SHIFT button and this button.

**Note 4:** The SHIFT button, which is often mentioned, is located at the level of the B note of the first octave, it is horizontal and there are no other buttons or indicators directly next to it.
