# PIANO Section

The PIANO section is the leftmost main section of the panel (after the Master controls). It has a light gray header background, a frame of the same color, and a dark gray background inside.

The Nord Piano 6 includes a wide range of piano and keyboard sounds from the ever-growing Nord Piano Library. New sounds are regularly available free at nordkeyboards.com.

---

## Master Controls (Far Left, Before PIANO Section)

### MASTER LEVEL Knob

A **round knob** at the top-left of the panel, before the PIANO section begins.

- Sets the overall output level for **all outputs** — Left/Right line outputs and headphones.
- Rotating left = lower volume; rotating right = higher volume.
- **Unlike all other knobs**, the Master Level value is **not stored with programs**. It always reflects its physical position.

### VIBRATO Button

A **gray rectangular button** below the Master Level knob. Below the button is a round indicator labeled **ENABLE**.

- Pressing this button applies vibrato in real time to the Sample Synth sound, using the Rate and Amount settings set in the Sample Synth section.
- **ENABLE** (Shift + Vibrato): turns this vibrato button function on or off **per layer**. This lets you apply vibrato to one layer but not the other — useful in split mode.

## Layer Controls (Left Half of PIANO Section)

### Layer A and B Faders

Two **vertical sliders** at the top-left of the PIANO section, side by side.

- **Left fader** = Layer A level; **Right fader** = Layer B level.
- Each fader has a 12-segment green LED bar graph to the right of it, showing the current output level.
- Turning on the Piano section is done by pressing either **LAYER A** or **LAYER B** button below the faders.

### LAYER A and LAYER B Buttons

Each fader has a **gray button** below it:

- **Left button** = LAYER A
- **Right button** = LAYER B

Above each button: inscription **ON/OFF** with a down arrow.
Below each button: a small round **orange indicator** labeled **LAYER A** or **LAYER B**.

**How layers work:**

| Action | Result |
|---|---|
| Press one layer button | Turn that layer on; focus it for editing |
| Press both buttons simultaneously | Turn on the second layer |
| Hold a layer button | Turn that layer off |
| Press the inactive layer's button (when both are on) | Switch focus to that layer |

When both layers are active, the **focused layer's LED blinks**. When a layer is focused for effects editing, its LED lights **red** and the **FX FOCUS** LED in the Effects section confirms it.

### KB ZONE Indicators and Assignment

Below each layer button are **two small round green LEDs**: labeled **LO** (lower) and **UP** (upper). Between them is the label **KB ZONE**.

- **KB ZONE** (Shift + Layer A or B): assigns the focused layer to a keyboard zone.
- **LO** = lower zone (left of split point); **UP** = upper zone (right of split point); both lit = full keyboard.
- Used together with the KB SPLIT function in the Program section.

### OCTAVE SHIFT Buttons

Below the KB ZONE area is the heading **OCTAVE SHIFT** with left and right arrows. Below it are **two black buttons**.

- **Left button (down arrow)**: transposes the selected Piano layer **down one octave** (−12 semitones).
- **Right button (up arrow)**: transposes the selected Piano layer **up one octave** (+12 semitones).
- When a layer is assigned to the full keyboard, it can shift one octave up or down.
- When assigned to a smaller zone, the available transpose range varies — but always keeps the full piano sound range accessible.

**Secondary functions (Shift):**

- **SUST PED** (Shift + left Octave Shift button): activates any connected sustain pedal for the selected Piano layer. Red indicator to the left of the label.
- **VOL PED** (Shift + right Octave Shift button): activates the connected volume/expression pedal for the selected Piano layer. The LED fader still sets the maximum volume. Red indicator to the left of the label.
