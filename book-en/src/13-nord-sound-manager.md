# Nord Sound Manager

Nord Sound Manager is a free application for managing the Nord Piano 6 sound library from a computer. Download it at **nordkeyboards.com**.

---

## What Nord Sound Manager Does

- Downloads new piano sounds and samples to the instrument
- Deletes sounds to free up memory
- Renames programs
- Organizes programs into banks
- Creates backups of all programs and sounds
- Installs operating system updates

---

## Connecting

1. Connect the Nord Piano 6 to your computer using a **USB Type B** cable (the square-connector type used by printers).
2. Launch Nord Sound Manager. The instrument is detected automatically.
3. No additional drivers are needed on Mac or Windows.

---

## Program Window Layout

The window is divided into two panels:

**Left — the instrument:** shows the contents of the Nord Piano 6's memory, organized by section (Piano, Samples, Programs).

**Right — the archive:** shows the contents of a selected folder on your computer.

To transfer a sound: drag it from the archive panel onto the instrument panel. To delete: select a sound in the left panel and press Delete.

---

## Downloading New Sounds

1. Download a `.npno` (piano) or `.nsmp` (sample) file from nordkeyboards.com.
2. Open Nord Sound Manager.
3. Drag the downloaded file into the appropriate section of the instrument panel.
4. The new sound is immediately available on the instrument after transfer.

---

## Updating the Operating System

1. Download the OS update file from nordkeyboards.com.
2. Open Nord Sound Manager.
3. Click **Update OS** and select the downloaded file.
4. Do not disconnect USB or power off during the update.

---

## File Formats

| Extension | Contents |
|---|---|
| `.npno` | Piano sound (Nord Piano Library) |
| `.nsmp` | Sample instrument (Nord Sample Library) |
| `.nprg` | Single program |
| `.nbank` | Program bank (36 programs) |
| `.nbundle` | Full backup (all programs and sounds) |
