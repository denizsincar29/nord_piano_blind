# Nord Sample Editor 4

Nord Sample Editor 4 is a free application for creating custom sample instruments from WAV or AIFF audio files. Download it at **nordkeyboards.com**.

---

## What It Lets You Do

- Import your own WAV or AIFF recordings
- Assign samples to individual keys or keyboard zones
- Set start, end, and loop points for each sample
- Configure voice count, tuning, and panning per zone
- Export the finished instrument as an `.nsmp` file and send it to the Nord Piano 6

---

## Connecting

Same as for Nord Sound Manager — connect using a **USB Type B** cable. The application detects the instrument automatically on launch.

---

## Key Concepts

**Instrument** — a collection of samples organized into keyboard zones. One instrument occupies one slot in the Nord Piano 6 Sample library.

**Zone** — a key range to which one sample is assigned. An instrument can contain up to 256 zones.

**Root key** — the note at which the sample plays back at its original pitch. Notes above and below the root key are transposed accordingly.

**Loop** — a loop point that causes the sample to repeat between two set positions, allowing a note to sustain indefinitely.

---

## Workflow

1. Record or prepare your audio files (WAV at 44.1 kHz, 16 or 24 bit recommended).
2. Create a new instrument in Nord Sample Editor 4.
3. Drag your audio files into the program window — each file becomes a zone.
4. Assign a key range and root key to each zone.
5. Configure loop points if needed.
6. Click **Send to Nord** — the instrument is transferred to the Nord Piano 6 and is immediately accessible in the Sample section.

---

## Memory Limits

The Nord Piano 6 has **512 MB** of sample memory. The size of each instrument depends on the number and length of samples. Nord Sample Editor shows current and available memory in real time during transfer.
